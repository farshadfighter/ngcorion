# پیکربندی سیستم

تنظیمات خود NGCorion، هر کدام در یک کارت. همهٔ رازهای این بخش (رمز SMTP، کلید API پیامک، community و کلیدهای SNMP، رمز حساب‌ها) رمزنگاری‌شده ذخیره می‌شوند و دوباره نمایش داده نمی‌شوند؛ برای تعویض، مقدار تازه را وارد کنید.

## کارت‌ها

| کارت | کاربرد |
|---|---|
| تنظیمات زمان | منطقهٔ زمانی و سرور NTP؛ ساعت درست برای ورود دومرحله‌ای، زمان‌بندی‌ها و دنبالهٔ ممیزی لازم است. منطقه را با نام فارسی، نام شهر یا اختلاف ساعت جستجو کنید (مثلاً «تهران» یا ‎+03:30)؛ پیش‌فرض Asia/Tehran است |
| تنظیمات SNMP | عامل SNMP خود سرور NGCorion، تا NMS سازمان آن را پایش کند |
| تنظیمات Syslog | ارسال لاگ‌های سیستم‌عامل سرور و هشدارهای CEF به SIEM |
| تنظیمات پیامک | درگاه پیامک (کاوه‌نگار، قاصدک، sms.ir یا هر درگاه HTTP) برای هشدارها و کد بازیابی رمز عبور. برای sms.ir شمارهٔ خط حساب لازم است. اینکه چه چیزی با پیامک برود در [سیاست ارسال](/settings/notifications) تعیین می‌شود |
| تنظیمات SMTP | سرور ایمیل برای هشدارها، گزارش‌های زمان‌بندی‌شده و کد بازیابی رمز؛ با دکمهٔ «ارسال آزمایشی» |
| تنظیمات گواهی | گواهی TLS رابط وب (PEM یا PFX)؛ فقط TLS 1.2 و 1.3 |
| زبان | زبان پیش‌فرض کاربران جدید |
| مهلت‌های اصلاح | مهلت رفع هر شدت و حداکثر مدت پذیرش ریسک |
| گزارش‌ها | نام و لوگوی سازمان روی گزارش‌ها و مدت نگهداری آن‌ها |
| کلیدهای پین‌شدهٔ دستگاه‌ها | کلیدهای SSH و گواهی‌های ثبت‌شدهٔ دستگاه‌ها؛ حذف فقط پس از تأیید تغییر |
| ورود دومرحله‌ای | نقش‌هایی که باید کد گوشی بزنند و مهلت راه‌اندازی |
| Active Directory / LDAP | ورود با حساب سازمانی و نقش از گروه‌های دامنه |
| پروفایل‌های اعتبارنامه | اطلاعات ورود رمزنگاری‌شده برای ممیزی و پشتیبان‌گیری گروهی |

## ترتیب پیشنهادی پس از نصب

1. تنظیمات زمان (NTP داخلی سازمان).
2. تنظیمات گواهی (گواهی سازمان برای نام سامانه).
3. تنظیمات SMTP و ارسال یک ایمیل آزمایشی به خودتان.
4. ورود دومرحله‌ای و، در صورت وجود دامنه، Active Directory / LDAP.
5. پروفایل‌های اعتبارنامه، هر کدام با «آزمایش» ورود روی یک دارایی (فقط وارد می‌شود و چیزی را تغییر نمی‌دهد).

## نمونه: پروفایل اعتبارنامه

| نام | نوع | حساب دستگاه | برای |
|---|---|---|---|
| `linux-audit` | SSH | `ngc-audit` با رمز sudo | سرورهای لینوکس |
| `netdev-ssh` | SSH | `ngc-audit` با Enable secret | Cisco و FortiGate |
| `win-domain` | WinRM | `CORP\svc-ngc-audit` | ویندوز، AD، DNS، DHCP، IIS |

رمز پروفایل فقط‌نوشتنی است و هیچ صفحه‌ای آن را برنمی‌گرداند. دورهٔ تعویض (پیش‌فرض ۹۰ روز) هشدار «زمان تعویض گذرواژهٔ پروفایل اعتبارنامه رسیده است» را راه می‌اندازد.

## مراقب باشید

> حذف یک کلید پین‌شده یعنی اتصال بعدی کلید تازه را بی‌پرسش می‌پذیرد؛ فقط وقتی حذف کنید که تغییر کلید را با مالک دستگاه تأیید کرده‌اید. برای پروفایل‌ها حساب جداگانه با کمترین دسترسی بسازید، نه حساب مدیر مشترک. هر تغییری در این صفحه در دنبالهٔ ممیزی ثبت می‌شود.
