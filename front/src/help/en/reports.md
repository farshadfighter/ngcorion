# Build a report

Each report starts from a ready template; you choose the period, assets, sections, language and file format. The report is built in the background and lands in the [Archive](/reports/archive).

## Which template for whom

| Audience | Template |
|---|---|
| CEO and board | Executive security summary |
| Auditor (PCI, ISO) | Compliance with a standard, one audit in detail, hardening changes, remediation and accepted risks |
| Security team | Vulnerabilities (CVE), risk of assets, end of life, TLS certificates, software inventory |
| Network and infrastructure | Assets and coverage, backup and restore, availability (NOC), architecture validation |
| System administrator | Alerts, user activity |

## Build one

1. "Build report" on the template.
2. **Title** and **period** (turn on "Compare with the previous period" for trends).
3. **Assets** (none chosen means all) and **sections**.
4. **Language:** Persian with Solar Hijri dates or English with Gregorian dates. **File format:** PDF, Excel or both.
5. **Classification** (e.g. "Confidential"), printed on every page, and the page orientation.
6. "Preview PDF" → check → "Build report".

## Example

Last month's executive summary: period "last month", every asset, compared with the previous period, Persian, PDF, classification "Confidential". To have it sent every month, use "Save as a schedule…" instead of "Build report".

## Take care

> Only data you may read goes into a report; a section from a module you cannot read is disabled. A schedule needs a moving period (e.g. "last month"), not fixed dates. Build the report of one audit session from that audit's own page.
