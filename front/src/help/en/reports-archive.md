# Report archive

Every report that was built, with its code (`RPT-…`), period, build time, files and status. Download files here, build a report again, pin it, or check a file's authenticity.

## Main tasks

- **Download:** the PDF or Excel of a report.
- **"Build again":** the same settings with today's data; a new report with a new code, and the earlier file is kept.
- **"Pin":** a pinned report is not removed when the retention period passes. Pin the reports you gave to an auditor.
- **Delete:** the files go too, and a copy handed out earlier can no longer be checked.

Filters: "Built by me", "Scheduled", "Being built", "Failed" and "Pinned"; and a search on the title or code.

## Check a file's authenticity

An auditor or manager has a file from you and wants to be sure it was not altered:

1. "Check a file…".
2. Drop or choose the PDF or Excel file.
3. The result:
    - **"Authentic: this file was built by NGCorion and has not changed."**
    - **"Not found: no report in the archive has exactly this content."** The file was changed after it was built, was not built here, or was deleted from the archive.

The check uses a SHA-256 hash; changing even one character makes the file fail.
