📘 توضیحات کامل فایل router_with_auth.py

🎯 هدف کلی برنامه

این فایل یک سیستم مدیریت دارایی‌های سازمانی (Asset Management) با احراز هویت کامل است. این برنامه با استفاده از فریمورک FastAPI نوشته شده و تمامی APIهای لازم برای مدیریت دارایی‌های IT یک سازمان را فراهم می‌کند.

🔐 سیستم امنیتی

نکته مهم: تمامی مسیرهای (Routes) این برنامه نیازمند احراز هویت JWT هستند. کاربر باید قبل از دسترسی به هر API، توکن معتبر خود را ارسال کند.

سطوح دسترسی:

  • کاربر عادی (User): فقط می‌تواند دارایی‌های خود را مشاهده کند
  • مدیر (Manager): دسترسی به ویرایش دارایی‌ها دارد
  • ادمین (Admin): دسترسی کامل به همه عملیات‌ها دارد

📦 ماژول‌های اصلی برنامه

این برنامه شامل 9 ماژول اصلی است که هر کدام مسئول مدیریت بخش خاصی هستند:

ماژول توضیحات مسیر API
Asset Types مدیریت انواع دارایی‌ها /api/asset-types
Assets مدیریت دارایی‌های اصلی /api/assets
Owners مدیریت مالکان دارایی‌ها /api/owners
Locations مدیریت مکان‌های فیزیکی /api/locations
Network Zones مدیریت زون‌های شبکه /api/zones
OS Catalog فهرست سیستم‌عامل‌ها /api/os-catalog
Vendors مدیریت تامین‌کنندگان /api/vendors
Dependencies وابستگی‌های بین دارایی‌ها /api/dependencies
Security Status وضعیت امنیتی دارایی‌ها /api/security

📋 توضیحات تفصیلی هر ماژول

1️⃣ Asset Types (انواع دارایی‌ها)

این ماژول برای دسته‌بندی انواع دارایی‌ها استفاده می‌شود (مثل سرور، لپ‌تاپ، روتر و ...)

GET /api/asset-types/

دریافت لیست تمام انواع دارایی‌ها

🔓 دسترسی: تمام کاربران احراز هویت شده
POST /api/asset-types/

ایجاد نوع دارایی جدید

🔒 دسترسی: فقط ادمین
GET /api/asset-types/{type_id}

دریافت اطلاعات یک نوع دارایی خاص بر اساس شناسه

🔓 دسترسی: تمام کاربران احراز هویت شده
PUT /api/asset-types/{type_id}

بروزرسانی اطلاعات نوع دارایی

🔒 دسترسی: فقط ادمین
DELETE /api/asset-types/{type_id}

حذف نوع دارایی

🔒 دسترسی: فقط ادمین

2️⃣ Assets (دارایی‌های اصلی)

مهم‌ترین ماژول برنامه که تمام دارایی‌های سازمان را مدیریت می‌کند.

GET /api/assets/

دریافت لیست دارایی‌ها

  • ادمین: تمام دارایی‌های سیستم را می‌بیند
  • کاربر عادی: فقط دارایی‌های خودش را می‌بیند
قابلیت صفحه‌بندی: می‌توانید با استفاده از پارامترهای page و page_size نتایج را صفحه‌بندی کنید.
🔓 دسترسی: تمام کاربران احراز هویت شده
POST /api/assets/

ایجاد دارایی جدید

اگر user_id مشخص نشود، دارایی به کاربر جاری اختصاص داده می‌شود.
🔒 دسترسی: فقط ادمین
GET /api/assets/{asset_id}

دریافت اطلاعات یک دارایی خاص

بررسی دسترسی: کاربر یا باید ادمین باشد یا مالک دارایی باشد
🔓 دسترسی: ادمین یا مالک دارایی
PUT /api/assets/{asset_id}

بروزرسانی دارایی

🔒 دسترسی: ادمین یا مدیر
DELETE /api/assets/{asset_id}

حذف دارایی

🔒 دسترسی: فقط ادمین

🔑 ویژگی‌های کلیدی برنامه

1. احراز هویت JWT

تمام درخواست‌ها نیازمند توکن JWT معتبر هستند. کاربران باید ابتدا لاگین کنند و توکن دریافت کنند.

2. کنترل دسترسی مبتنی بر نقش (RBAC)

سه سطح دسترسی وجود دارد:

  • User: دسترسی به دارایی‌های شخصی
  • Manager: دسترسی به ویرایش دارایی‌ها
  • Admin: دسترسی کامل به همه منابع

3. صفحه‌بندی (Pagination)

برای جلوگیری از بارگذاری حجم زیاد داده، قابلیت صفحه‌بندی در GET /api/assets/ پیاده‌سازی شده است.

4. اعتبارسنجی داده‌ها (Validation)

تمام داده‌های ورودی با استفاده از Pydantic schemas اعتبارسنجی می‌شوند (مثل بررسی فرمت IP، MAC Address، Email و ...)

5. مدیریت خطاها

برنامه خطاهای مختلف را به صورت استاندارد مدیریت می‌کند:

  • 404: منبع یافت نشد
  • 403: دسترسی غیرمجاز
  • 401: احراز هویت نشده

🎯 کاربردهای این برنامه

  • 🖥️ مدیریت دارایی‌های IT: سرورها، لپ‌تاپ‌ها، تجهیزات شبکه
  • 📍 پیگیری مکان فیزیکی: کدام دارایی در کدام اتاق/رک قرار دارد
  • 👤 مدیریت مالکیت: مشخص کردن مسئول هر دارایی
  • 🔐 ممیزی امنیتی: بررسی وضعیت امنیتی تجهیزات
  • 🌐 مدیریت شبکه: آدرس IP، MAC، VLAN و ...
  • 🔗 نقشه وابستگی‌ها: شناسایی ارتباطات بین دارایی‌ها
  • 📊 گزارش‌گیری: نماهای مختلف برای تصمیم‌گیری بهتر

💡 نحوه استفاده

برای استفاده از هر API:

  1. ابتدا با استفاده از API لاگین، توکن JWT دریافت کنید
  2. توکن را در هدر Authorization به صورت Bearer TOKEN ارسال کنید
  3. بسته به نقش کاربری خود، به APIهای مجاز دسترسی پیدا کنید
مثال:
GET /api/assets/
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

📝 خلاصه

این برنامه یک سیستم جامع مدیریت دارایی‌های IT است که با امنیت بالا (JWT)، کنترل دسترسی دقیق (RBAC)، اعتبارسنجی کامل داده‌ها و امکانات پیشرفته‌ای مثل صفحه‌بندی و گزارش‌گیری، سازمان‌ها را قادر می‌سازد تا دارایی‌های خود را به صورت حرفه‌ای مدیریت کنند.
