
( Field / Type / Why / Related CIS Controls / Validation)

A) General / Topology

1) Device Role
 • Field: device_role
 • Type: Dropdown (branch, dc, core, edge, access)
 • Why: بعضی کنترل‌ها مثل ACL روی External وابسته به نقش دستگاه است.
 • Controls: 3.2.1, 3.2.2
 • Validation: Required

2) External (WAN/Internet) Interface
 • Field: external_interface
 • Type: Dropdown (list interfaces from discovery) or Text
 • Why: برای اعمال ip access-group in روی اینترفیس خارجی
 • Controls: 3.2.2
 • Validation: Required if ACL hardening enabled

3) Management Source Interface (Preferred)
 • Field: mgmt_source_interface
 • Type: Dropdown (interfaces + loopbacks)
 • Why: برای logging source-interface و (اختیاری) SNMP/NTP/AAA source
 • Controls: 2.2.7, 2.4.2, 2.4.3 (و در عمل SNMP/NTP/AAA)
 • Validation: Optional but recommended

⸻

B) AAA (Authentication/Authorization/Accounting)

B1) AAA Enable/Method

4) Enable AAA New-Model
 • Field: aaa_enable_new_model
 • Type: Toggle (default ON)
 • Why: پایه‌ی AAA
 • Controls: 1.1.1

5) AAA Backend Type
 • Field: aaa_backend_type
 • Type: Dropdown (local, tacacs, radius, mixed)
 • Why: مشخص می‌کند کدام config باید ساخته شود
 • Controls: 1.1.2–1.1.10
 • Validation: Required if AAA enabled

B2) AAA Servers

6) AAA Servers List
 • Field: aaa_servers[]
 • Type: Repeater list objects:
 • type (tacacs/radius)
 • ip_or_fqdn
 • secret
 • port (optional)
 • vrf (optional)
 • Why: بدون سرور و secret، AAA fail می‌شود
 • Controls: 1.1.2–1.1.10
 • Validation: Required if backend != local

B3) AAA Policy for Services

7) Login Authentication Target
 • Field: aaa_apply_to
 • Type: Multi-select (vty, enable, http)
 • Why: CIS گفته برای login/enable/http AAA اعمال شود
 • Controls: 1.1.2, 1.1.3, 1.1.4, 1.1.5

B4) Accounting Policy

8) Enable Accounting Sections
 • Field: aaa_accounting_enable
 • Type: Multi-toggle:
 • commands_15
 • connection
 • exec
 • network
 • system
 • Why: مطابق کنترل‌های accounting
 • Controls: 1.1.6–1.1.10
 • Validation: Optional (but CIS recommends ON)

9) Enable Secret

 • Field: enable_secret_value

 • Field: local_users[]

 • Controls: 1.4.3
